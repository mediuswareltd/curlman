# Getting started

Install and run **Curlman** locally.

## Prerequisites

- Working knowledge of TypeScript
- Git and a terminal

## Install

```bash
# download from Releases, or build locally
npm install
npm run tauri build
```

## Quick start

```bash
npm install
npm run tauri dev
```
