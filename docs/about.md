# About Curlman

## Who maintains it

Curlman is built and maintained by [Mediusware](https://mediusware.com), a software company that designs and ships products for clients worldwide. The source lives at [github.com/mediuswareltd/curlman](https://github.com/mediuswareltd/curlman).

## Why it exists

A fast, minimal Tauri desktop app for running raw cURL commands with shell-accurate parsing and readable responses.

We publish these tools so teams can evaluate the real software, not a slide deck: clone it, run it, and read how it is put together.

## Documentation

- Docs site: https://mediuswareltd.github.io/curlman/
- Getting started, guide, and about pages are generated from the project README and kept next to the code under `docs/`.
