# Guide

## What it is

A fast, minimal Tauri desktop app for running raw cURL commands with shell-accurate parsing and readable responses.

## Stack

`Tauri`, `TypeScript`, `cURL`

## Capabilities

### Raw cURL first

No form rebuilds; paste browser Copy as cURL as-is.

### Shell-accurate parsing

bash/zsh quoting, continuations, and Windows cmd escapes.

### Readable responses

Pretty JSON, HTML preview, images, timing breakdown.

### Tiny desktop app

Tauri + system WebView; small installer and memory footprint.
